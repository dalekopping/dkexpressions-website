DK EXPRESSIONS V4 — TIME TRAVELLERS
===================================

Version 1.0.0

This is an installable WordPress theme for the DK Expressions staging website.

INSTALLATION
------------
1. Back up the staging website and database.
2. In staging WordPress, go to Appearance > Themes > Add New > Upload Theme.
3. Select dk-expressions-v4.zip.
4. Click Install Now.
5. Preview the theme before activation when WordPress offers that option.
6. Activate only on the /dkexpressions3/ staging installation.
7. Go to Settings > Permalinks and click Save Changes once.
8. Go to Appearance > Menus and assign the primary menu if required.

WHAT THE THEME INCLUDES
-----------------------
- Cinematic portal homepage
- White transparent DK Expressions logo
- Responsive desktop, tablet and mobile layout
- Solutions, Our Work, Industries, Insights, About, Legacy and Contact pages
- Dynamic latest-posts section
- Premium editorial article template
- Article archives, search results and custom 404 page
- Featured images and responsive embeds
- Fallback SEO metadata, Open Graph and organisation schema
- Yoast SEO, Rank Math and AIOSEO compatibility
- Reduced-motion accessibility support
- Reading-progress indicator

IMPORTANT
---------
- This theme does not delete posts, pages, images, users or plugins.
- Activating it changes only the presentation of the selected WordPress installation.
- Use it on staging first.
- Keep staging blocked from search indexing until launch.
- Existing article URLs remain controlled by WordPress permalinks and should not be changed during activation.
