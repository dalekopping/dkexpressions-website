# DK Expressions Approved Fixes — v1.29.0

## Exact media-slot placement

- Converts the numbered Selected Work placeholders into explicit WordPress media slots.
- Tapping an empty frame now opens a single image-or-video replacement action instead of treating its number as text.
- Places the selected upload inside the intended card frame while keeping the category and caption in their approved positions.
- Automatically moves legacy Visual Studio insertions into an empty media slot when an earlier release stored them after the card.
- Supports images and videos in the same empty frame on desktop, tablet and mobile.
- Preserves the locked DK colour, typography, spacing and responsive layout system.
