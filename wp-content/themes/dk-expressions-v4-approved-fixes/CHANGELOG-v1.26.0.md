# DK Expressions V4 Approved Fixes — v1.26.0

## Visual Page Studio

- Replaces the copy-only backend experience with an exact saved-frontend canvas inside WordPress.
- Adds desktop, tablet and mobile canvas widths.
- Allows authorised editors to click visible page text and edit it in position.
- Allows images and videos to be replaced through the native WordPress Media Library.
- Connects recognised copy to its existing server-rendered Page meta field.
- Supports page-specific visual overrides for visible elements that are not part of the original field manifest.
- Adds a global DK logo media replacement while preserving the approved white-logo fallback.
- Keeps the locked frontend layouts, typography, colour system, responsive rules and dynamic WordPress collections intact.
- Provides direct links to Posts, Press Categories, Media, Clients & Brands and Giveaways where those records remain the canonical source.
- Avoids the standard WordPress draft-preview link by using a signed same-session visual canvas.
