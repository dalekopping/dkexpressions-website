# DK Expressions Approved Fixes — v1.30.0

## Direct post and Page uploads

- Adds an explicit **Upload new image or video** action to the DK Visual Page Studio.
- Uploads directly from desktop, tablet or mobile without depending on the Media Library modal's upload tab.
- Attaches each new file to the post or Page currently being edited.
- Places the successful upload into the selected DK media frame or directly after the selected content position.
- Shows clear file-size, file-type, permissions and server rejection messages when WordPress cannot accept an upload.
- Keeps the existing **Choose from Media Library** workflow for files already uploaded.
- Adds the DK Visual Editor action to WordPress Posts as well as Pages.
- Preserves the locked frontend structure, DK colour system, typography and responsive styling.

## Release

- Bumps the theme and visual-editor cache release to 1.30.0.
