INSTALLATION
1. Back up the current active child theme and database.
2. WordPress Admin > Appearance > Themes > Add New > Upload Theme.
3. Upload this ZIP. WordPress may ask to replace the existing theme.
4. Activate “DK Expressions V4 — Approved Fixes”.
5. Clear all WordPress/server/CDN caches.
6. Ensure the page at /home/ uses template “DK Expressions Home — Enterprise”.
7. Review desktop, tablet and mobile before publishing.

ROLLBACK
Upload and activate the supplied rollback ZIP (v1.11.1), then clear caches.
