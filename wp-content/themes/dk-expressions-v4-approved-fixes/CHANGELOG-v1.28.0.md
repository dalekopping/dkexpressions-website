# DK Expressions Approved Fixes — v1.28.0

## Complete mobile media editing

- Compacts the mobile Visual Page Studio header, canvas controls and selected-element panel.
- Fixes hidden media controls appearing during text editing.
- Adds explicit support for replacing standard images, existing videos and CSS background images.
- Adds a mobile-safe “Add image or video here” action at any selected content position.
- Opens the native WordPress Media Library with its Upload Files workflow for new images and videos.
- Stores inserted images and videos as page-specific visual media while preserving the locked DK templates.
- Allows added media to be replaced or removed later from the same visual editor.
- Uses a true 360px editing canvas inside narrow WordPress admin screens so frontend mobile breakpoints render correctly.
- Adds responsive public styling for user-inserted images and videos.
- Bumps the theme and visual-editor cache release to 1.28.0.
