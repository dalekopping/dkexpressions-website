# DK Expressions Approved Fixes — v1.27.0

## Device-independent Visual Page Studio

- Adds a native selected-text editor that works reliably on phones and tablets without depending on `contenteditable` inside an iframe.
- Preserves inline DK colour styling by editing the exact touched text node when possible.
- Turns the selected-element inspector into a touch-friendly bottom panel on tablet and mobile.
- Adds large Apply, Media Library, Restore and Save controls inside the mobile panel.
- Automatically opens the matching mobile or tablet canvas when the studio is used on those devices.
- Keeps direct on-canvas typing available for desktop pointer devices.
- Improves mobile canvas height, button sizes, spacing and touch targets.
- Bumps all relevant cache versions to 1.27.0.
